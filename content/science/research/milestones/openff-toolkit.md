## Overview

The OpenFF Toolkit is the core open-source Python library for applying SMIRNOFF force fields to molecular systems. It introduced direct chemical perception via SMARTS-based typing as the foundation for all subsequent OpenFF force fields.

The Toolkit supports RDKit and OpenEye backends, exports to OpenMM, GROMACS, AMBER, and CHARMM, and provides a clean Python API for loading, modifying, and applying force field parameters.

Key capabilities added across major releases include:
- **0.2** — RDKit support, SMIRNOFF 0.2 XML specification
- **0.6** — Library charges, conda installers
- **0.7** — Flexible partial charges, WBO torsion interpolation
- **0.8** — Virtual site support, improved biopolymer infrastructure
- **0.9** — Biopolymer parameterisation
